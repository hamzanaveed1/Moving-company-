## Rules for every post
- One primary keyword in title, H1 and first 100 words.
- 1 internal link to a service page, 1 to a city or route page, 1 to the quote page.
- A 1600x900 cover image (`npm run images` makes the illustrations, or drop in a real photo) with descriptive alt text.
- Add a real `updatedAt` date when you refresh figures.
- Only state UK facts you have checked (rules, fees and zones change).
