# MovingPal media kit

| Folder | What | Where to use it |
|---|---|---|
| `1-profile-photos/` | Logo-mark profile photos (white and navy) at 1080x1080, plus the detailed round WhatsApp badge | LinkedIn, Facebook, Instagram profile picture (all show it in a circle: the mark sits safely inside); WhatsApp Business |
| `2-banners/` | LinkedIn personal banner 1584x396, LinkedIn company-page banner 1128x191, Facebook cover 1640x624 | LinkedIn / Facebook cover images. The left side is kept clear for the profile photo; on phones Facebook crops the sides, so the key content sits in the middle |
| `3-posts/` | 10 posts in 3 sizes: LinkedIn 1200x627, Facebook 1080x1080, Instagram 1080x1350 | The first ten posts. Wording in `CAPTIONS.md` |

Instagram has no banner image, so it uses a profile photo only.

Regenerate everything with `npm run media-kit` (edit wording in `scripts/media-kit-posts.mjs`).
